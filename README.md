# PDF 转图片 · 单文件网页版

一个 HTML 文件搞定 PDF → 图片。双击打开就能用，不装任何东西，**PDF 不会上传到任何服务器**。

在线转换站要你先把文件传上别人的服务器；本地软件又太重。这个工具把渲染引擎放在浏览器里跑，文件从头到尾只在你自己的内存里。

## 功能

- **零上传** —— 全程本地解析，不发起任何文件上传请求
- **单文件** —— 一个 `pdf2img.html`，双击即用，不需要安装，也不需要起本地服务
- **格式** —— PNG（无损）/ JPEG / WebP
- **清晰度** —— 1–6 倍率，或直接指定目标宽度（如公众号 1080px），宽高比自动保持
- **页面范围** —— 支持 `1-5`、`1,3,7-9` 这类写法
- **方向修正** —— 旋转 90 / 180 / 270 度，救回方向不对的扫描件
- **背景** —— 白色 / 透明（PNG、WebP）/ 自定义底色
- **批量** —— 多文件排队转换，可打包 ZIP 下载，也可直接写入你指定的文件夹
- **防呆** —— 超大页面自动降倍率，避免浏览器被拖卡死；可自动跳过完全空白的页

## 使用方法

1. 下载 [`pdf2img.html`](pdf2img.html)
2. 双击，用 Chrome 或 Edge 打开
3. 把 PDF 拖进去（或点击选择文件，或按 `Ctrl+V` 粘贴）
4. 调好参数 → 点「开始转换」→ 下载

首次打开需要联网加载渲染库（约 700 KB），之后浏览器会缓存，断网也能继续用。

## 为什么固定用 4.10.38，而不是最新版

渲染引擎是 [pdf.js](https://github.com/mozilla/pdf.js)。npm 上现在最新是 6.x，这里固定 **4.10.38**，理由是 **6.x 引入了 wasm 依赖**（源码里 `wasmUrl` 出现 11 次，4.x 是 0 次）。单文件、免安装的场景下，外部依赖越少越不容易坏。

顺带说明：`page.render({canvasContext, viewport})` 在 4.x 和 6.x 都是合法签名，所以这不是 API 不兼容，纯粹是依赖面的取舍。

## 实现要点

- 依赖走 CDN，三源自动回退：jsDelivr → unpkg → cdnjs
- `GlobalWorkerOptions.workerSrc` 交给 pdf.js 自己处理。跨域 worker **不能**自己 `new Worker()`，浏览器会直接抛 `SecurityError`
- 不需要构建步骤，改完即用
- 浏览器直接双击（`file://` 协议）打开即可运行，不需要本地服务器

## 已知限制

**中文 PDF 如果字体没有嵌入文件、且使用 CID 编码，浏览器端渲染不出来。**

这不是本工具的 bug，是 pdf.js 的先天限制 —— 浏览器拿不到系统字体，配 cMap 也补不回来。

Word / WPS 导出的 PDF 字体是内嵌的，不受影响。如果你遇到渲染出来一片空白的文件，请改用 MuPDF 内核的命令行工具（例如 PyMuPDF），它可以直接调用系统字体补上。

## 兼容性

Chrome / Edge 实测通过，含直接双击以 `file://` 打开的场景。Firefox、Safari 14+ 理论上可用，未逐一实测。
